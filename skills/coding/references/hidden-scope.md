# A change wider than its ask

Neither of these throws. Each reaches past the change that was asked for.

- **Naming some elements is not a licence for the rest.** A restyle naming these lines, that row, this icon: change those, leave neighbours as they were, and name the mismatch.
- **Merging containers drops the values they inherited.** A colour on the list, a default on the group: nothing fails, the item renders plainer. Bake the value onto each item, then replay the old resolution against `git show HEAD:<path>` and count mismatches. A test against the new file cannot see a value it never had.

## What a removal or a narrowing reaches

- **A removed control goes down the chain.** Its prop, the caller's handler, the service method no caller reaches, the CSS rule and every selector list that names it. A leftover method reads as live code.
- **A narrowed render condition hides more than the task says.** Walk every element that function touched, not only the control the task names. Hiding the gear under the `searchOpen || settingsOpen` that showed the back button puts the gear back on screen in search.
- **A new member of a fixed set lands everywhere the set is read.** A key, a menu item, an action: the shared reader, every dispatch site, the test that counts the set, each comment that names the count. Grep the number word and the list. A stale count reads as a spec.
